SIGN-IN v4.0 – INSTALLATION & SETUP INSTRUCTIONS
=====================================================

1. INITIAL INSTALLATION & AUTO-START SETUP
------------------------------------------
When launching Sign-In v4.0 for the first time on your Android tablet, the "Auto-Start Setup" popup will appear.
To ensure the app opens automatically when the tablet reboots, please complete these two setup steps:
  1. Display over other apps: Enable permission on the system screen. (If the switch is disabled, tap the 3 dots at the top right of the system screen and select 'Allow restricted settings' first).
  2. Battery Optimization: Go to Tablet Settings > Apps > Sign-In v4.0 > Battery, and set it to "Unrestricted" to prevent OEM background process managers from terminating the app after reboot.

2. EXCEL DATA STRUCTURE (.xlsx)
------------------------------
Sign-In v4.0 integrates with Excel spreadsheets stored in Documents/Sign-In Data/:
  - Members (Cols A & B)
  - Cast Sheet (Row 1 Title, Row 2 Date, Row 3+ Names)
  - Roles & Locations sheets
  - Questions & Titles sheets

3. THEMES & CUSTOMIZATION
-------------------------
  - Custom Theme Color: Go to Admin > Appearance, tap "Click to change" on the right of the tile, and use the RGB sliders in the custom color engine to pick any custom color.
  - Dark Mode / Live Mode: Automatically transitions when no cast list is uploaded vs. when cast list is active.
  - Panel Headings: In Dark mode, panels display as "Members/Visitors (A-M)" and "Members/Visitors (N-Z)".

4. SIGN-IN SAFEGUARDS & LOG RETENTION
-----------------------------------
  - Duplicate Sign-In Safeguard: Prevents checking in twice by displaying an "Already Signed In" warning and resetting the name input box.
  - Guest Validation: Enforces AA AAA format for guest check-ins.
  - Warehouse Mode: Optional toggle (GPT / YT) for dedicated warehouse worksheets.
  - Log Retention & Unselected Folder Behavior: Admin logs are kept for 30 days, and sign-in records for 60–90 days (< 20 MB total). If no log save folder is selected, core sign-in and database persistence still work normally; external text log files and daily exports are simply skipped until a folder is selected.
